# InstantStudy™ — Software + Plugin

## Product definition

InstantStudy™ is a complete study software with an AI-native plugin surface.

### Software offer

1. Bring any material
   - paste text
   - upload documents
   - Google Drive
   - recorded lecture/audio

2. Generate study assets
   - Study Guide
   - Flashcards
   - Adaptive Learn
   - Practice Test
   - Ask
   - Review queue

3. Persist learning state
   - concept mastery
   - weak concepts
   - due reviews
   - study history

4. Monetize through the shared InstantPay funnel
   - Free
   - Plus
   - Unlimited

### Plugin offer

The same study engine is exposed to:
- ChatGPT
- Claude Code
- Cursor
- Codex
- any compatible MCP host

The plugin should not create a separate memory model. It should read and update the same learner knowledge state used by the software.

## Competitive mapping

The software mirrors the proven Quizlet category offer:
material -> generated study assets -> flashcards -> Learn -> Test -> understanding -> review.

InstantStudy differentiates through:
- original visual identity
- AI-agent portability
- one shared adaptive knowledge state
- content-first workflow with no mandatory deck setup

## Product constraint

Do not copy Quizlet logos, screenshots, proprietary UI, wording, source code, or branded assets. Match the product capabilities and conversion architecture using InstantStudy's own design and implementation.
