# InstantBible

**Scripture into practice, every day.**

Flutter MVP for a personalized Christian habit app built around:

**Scripture → Understand → Act → Reflect → Habit**

The product is not positioned as another Bible reader. It helps a user turn one biblical idea into one concrete daily action in about five minutes.

## MVP
- personalized onboarding
- trial/paywall
- Today home
- 5-step daily ritual
- reflection journal
- calm progress signal

## Run
If platform folders are not present, run:

```bash
flutter create . --platforms=android,ios,web
flutter pub get
flutter run
```

No third-party runtime packages are required in v0.1.

See DESIGN.md for the ElevenLabs/Refero-inspired visual system.
